# ECE Engineering Toolkit

A Python-based toolkit designed for Electronics and Communication Engineering (ECE) students.

## 📌 Project Description

ECE Engineering Toolkit provides simple calculators for common electrical and electronics concepts. It also includes a basic signal analysis feature for calculating RMS voltage.

## 🚀 Features

### 1. Ohm's Law Calculator
Calculates current using:

I = V / R

### 2. Power Calculator
Calculates electrical power using:

P = V × I

### 3. Resistance Calculator
Calculates resistance using:

R = V / I

### 4. Frequency / Time Period
Calculates frequency and time period using:

T = 1 / f

f = 1 / T

### 5. Signal Analyzer
Calculates RMS voltage for a sinusoidal signal:

Vrms = Vpeak / √2

### 6. Input Validation
Handles invalid inputs and prevents common calculation errors.
